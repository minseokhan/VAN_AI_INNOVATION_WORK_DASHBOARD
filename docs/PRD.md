# PRD: VAN AI 혁신부 업무 대시보드

## 목표
운영진이 약 20개 프로젝트의 배치·진행 상태·주간 개발 현황을 한눈에 파악하고, 부원은 자기 프로젝트의 진행을 매주 보고하며 기획 질문을 남길 수 있게 한다.

## 사용자
- **운영진(ADMIN)**: 프로젝트 생성/편집, 부원 배치, 가입 승인, 기획안 업로드, 질문 답변. 세부 구분으로 기획 운영진 / 개발 운영진 라벨을 가진다.
- **부원(MEMBER)**: 배치된 프로젝트의 기능 체크리스트·초기 정보·주간 보고를 갱신하고 질문을 올린다.

## 핵심 기능

### 1. 인증
- 아이디/비밀번호 자체 회원가입·로그인·로그아웃. 소셜 로그인 없음.
- 가입 직후는 `승인 대기` 상태. 운영진이 `/members`에서 승인해야 로그인 가능.
- 초기 운영진 계정은 시드로 생성(환경변수 `ADMIN_USERNAME`, `ADMIN_PASSWORD`).

### 2. 프로젝트 목록 (`/`)
- 상단 요약: 전체 / 미배정 / 진행중 / 완료 개수.
- 프로젝트 카드 그리드(데스크톱 3~4열, 모바일 1열). 카드에는 제목, 한 줄 요약, 상태 배지, 진행률 바, 팀원 아바타(이니셜), 최근 보고 날짜.
- 상태·검색 필터. 카드 클릭 시 상세로 이동.

### 3. 프로젝트 상세 (`/projects/[id]`)
- 헤더: 제목, 상태, 진행률(완료 기능 수 / 전체 기능 수로 자동 계산), 시작일.
- **기능 체크리스트**: 항목 추가/삭제/완료 토글. 완료 항목은 취소선. 팀원과 운영진만 편집.
- **팀**: 팀원 목록과 포지션(FE / BE / AI / PM / 기타).
- **초기 정보**: GitHub 주소, 배포 링크, 주 언어, DB/인프라 메모. 팀원이 작성·수정.
- **주간 보고 타임라인**: 주차별 보고 내용(이번 주 한 일, 다음 주 계획, 이슈). 최신순.
- **기획안**: 운영진이 올린 파일(pdf/docx/md 등) 또는 링크 목록. 다운로드/열기.
- **질문**: 이 프로젝트에 달린 질문과 답변 목록.
- 상태 변경: 팀원/운영진이 `진행중 ↔ 완료` 전환 가능. 팀원이 0명이면 자동으로 `미배정`.

### 4. 운영진 기능
- 프로젝트 생성/편집/삭제 (`/projects/new`, `/projects/[id]/edit`).
- **배치 보드 (`/assign`)**: 왼쪽에 부원 카드 목록, 오른쪽에 프로젝트 컬럼. 부원 카드를 프로젝트로 드래그하면 배치되고 드롭 애니메이션이 재생된다. 배치 후 포지션 선택. 배치 해제 가능.
- **멤버 관리 (`/members`)**: 가입 승인/거절, 운영진 지정/해제, 기획·개발 운영진 라벨 설정.
- 기획안 업로드 (파일 + 링크).
- 질문 답변.

### 5. 질문 (`/questions`)
- 부원이 자기 프로젝트를 선택하고 질문 작성(기획 문의, 방향 확인, 피드백 요청).
- 목록: 전체 / 내 프로젝트 / 미답변 필터. 운영진은 답변 작성.
- **디스코드 다이제스트**: 매일 18:00 KST에 아직 발송되지 않은 질문을 프로젝트별로 묶어 웹훅으로 전송. 기획자 역할을 멘션. 운영진은 `지금 보내기` 버튼으로 수동 발송 가능.

## MVP 제외 사항
- 소셜 로그인, 비밀번호 찾기(운영진이 수동 초기화)
- 실시간 알림, 댓글 스레드, 멘션
- 프로젝트별 채팅
- 디스코드 → 대시보드 역방향 연동(답변 수집)
- 모바일 앱, PWA
- 통계 차트(주차별 진행률 그래프 등) — 진행률 바와 숫자로 대체
