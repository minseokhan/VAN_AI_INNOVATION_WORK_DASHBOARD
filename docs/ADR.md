# Architecture Decision Records

## 철학
15명 규모 학회 부서용 내부 도구. 작동하는 최소 구현을 선택하고, 외부 의존성은 꼭 필요한 것만 추가한다. 운영진 한 명이 유지보수할 수 있어야 한다.

---

### ADR-001: Next.js 15 App Router 단일 앱
**결정**: 프론트와 백엔드를 Next.js 하나로 구성. Server Components + Server Actions.
**이유**: 별도 API 서버 없이 Vercel에 그대로 배포. 페이지 수가 적고 실시간 요구가 없다.
**트레이드오프**: 프레임워크 종속. 나중에 모바일 앱이 필요하면 API 레이어를 따로 뽑아야 한다.

### ADR-002: PostgreSQL + Prisma
**결정**: Vercel 배포 조건에 맞춰 Postgres(Neon 또는 Supabase) 사용, ORM은 Prisma.
**이유**: Vercel 서버리스에서는 SQLite 파일 저장이 불가능. Prisma는 스키마가 곧 문서가 되고 마이그레이션·시드가 내장돼 있다.
**트레이드오프**: 로컬 개발도 원격 DB(또는 Docker Postgres)가 필요. 콜드 스타트 시 커넥션 지연.

### ADR-003: 자체 인증 (bcryptjs + jose JWT 쿠키)
**결정**: NextAuth 등 라이브러리 없이 아이디/비밀번호 + httpOnly 쿠키 JWT.
**이유**: 소셜 로그인 불필요. 라이브러리를 쓰면 설정이 기능보다 커진다. jose는 Edge middleware에서 동작한다.
**트레이드오프**: 비밀번호 찾기, 세션 무효화 목록 등은 직접 만들어야 한다. MVP에서는 운영진 수동 초기화로 대체.

### ADR-004: 가입 승인제
**결정**: 누구나 가입 가능하되 `approved=false`로 시작. 운영진 승인 후 로그인.
**이유**: 초대 코드는 유출되면 무의미하고, 운영진 직접 생성은 운영 부담. 승인제는 두 문제를 모두 피한다.
**트레이드오프**: 운영진이 승인 작업을 잊으면 부원이 대기한다. 멤버 페이지 상단에 대기 인원을 강조 표시.

### ADR-005: 진행률은 체크리스트에서 계산
**결정**: 진행률 숫자를 저장하지 않고 `done` 기능 수 / 전체 기능 수로 계산.
**이유**: 자기보고 퍼센트와 체크리스트가 어긋나는 상태를 없앤다. 체크리스트가 곧 진실.
**트레이드오프**: 기능 항목을 세분화하지 않은 팀은 진행률이 거칠게 움직인다. 팀이 항목을 쪼개도록 안내.

### ADR-006: 기획안 파일은 @vercel/blob
**결정**: 파일 업로드는 Vercel Blob, 링크는 URL 문자열로 저장. 둘 다 `PlanDoc`으로 통합.
**이유**: Vercel 서버리스에서 로컬 디스크 저장 불가. Blob은 설정이 토큰 하나.
**트레이드오프**: Vercel 종속. 용량 과금. 파일 크기 상한 20MB로 제한.

### ADR-007: 디스코드 다이제스트는 Vercel Cron + 웹훅
**결정**: 봇 없이 웹훅 POST. `vercel.json` cron이 하루 1회 `/api/cron/digest`를 호출.
**이유**: 봇은 토큰 관리·상시 프로세스가 필요. 웹훅은 URL 하나로 끝난다. 역할 멘션은 `<@&ROLE_ID>` 문자열이면 된다.
**트레이드오프**: 디스코드에서 답변을 다시 가져올 수 없다. 답변은 대시보드에서 작성.

### ADR-008: 드래그 배치는 @dnd-kit/core
**결정**: 네이티브 HTML5 DnD 대신 dnd-kit 사용.
**이유**: 드롭 애니메이션과 터치 지원이 요구사항. 네이티브 DnD는 드래그 고스트 커스터마이징이 어렵다.
**트레이드오프**: 의존성 1개 추가. 배치 보드 외에는 쓰지 않는다.

### ADR-009: Tailwind v4 + 디자인 토큰
**결정**: 컴포넌트 라이브러리(shadcn 등) 없이 Tailwind v4 `@theme` 토큰과 소수의 자체 UI 컴포넌트.
**이유**: 필요한 컴포넌트가 10개 미만. 라이브러리 도입이 커스터마이징보다 비싸다.
**트레이드오프**: 접근성(포커스 링, aria)을 직접 챙겨야 한다. UI_GUIDE에 명시.

### ADR-010: 하네스 실행 주체
**결정**: step은 대화 중인 Claude 세션이 직접 수행. `scripts/execute.py`는 `claude -p` 자동 실행용으로 유지.
**이유**: 사용자가 진행 상황을 바로 보며 개입할 수 있다. 원본 하네스의 codex 의존은 제거.
**트레이드오프**: 무인 일괄 실행은 execute.py를 따로 돌려야 한다.
